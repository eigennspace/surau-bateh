# Absen PL memvendor komponen React design system, bukan mengimpor langsung

Absen PL sejauh ini hanya meminjam token CSS mentah dari `New Surau Bateh Lori Design System/tokens/` (lihat spec asli, Implementation Decisions), disalin apa adanya ke `absen-magang/styles/tokens/`. Untuk memperkaya tampilan halaman gerbang (`/`, `/login`, `/daftar`, `/absen`), kami memutuskan **absen-magang** juga mengadopsi lima komponen React siap pakai dari design system (`Button`, `Card`, `Input`, `Badge`, `Icon` di `components/core/` dan `components/forms/` — modul ES biasa, bukan bundle demo `ui_kits/website/` yang bergantung ke `window.SurauBatehLoriDesignSystem_*`), dengan cara **menyalinnya (vendor)** ke `absen-magang/components/ds/`, bukan mengimpor relatif langsung lintas folder repo.

Ini mengulang persis perdebatan [ADR 0002](0002-production-imports-design-system-components-directly.md) → [ADR 0003](0003-site-vendors-design-system-snapshot.md): impor langsung membuat build bergantung pada folder `New Surau Bateh Lori Design System/` hadir persis di sebelahnya, sedangkan `absen-magang` — seperti `site/` — adalah aplikasi terpisah yang bisa saja perlu di-deploy independen (repo ini belum punya konfigurasi deploy untuk `absen-magang` sama sekali, beda dengan `site/` yang sudah punya `.github/workflows/deploy.yml`). Berbeda dengan `site/`, vendoring ini **tidak** disertai skrip sync otomatis seperti `site/scripts/sync-design-system.mjs` (lihat [ADR 0009](0009-hapus-skrip-sync-ds.md), yang malah menghapus skrip serupa) — jumlah komponen yang divendor kecil (lima file) dan tidak sering berubah, jadi penyalinan manual sekali ini dianggap cukup; menyesuaikan manual saat berubah lagi dipandang lebih murah daripada memelihara skrip sync untuk kasus sekecil ini.

**Konsekuensi**: `absen-magang/components/ds/` bisa drift secara visual dari `New Surau Bateh Lori Design System/components/` di antara dua kali penyalinan manual — sama seperti risiko yang sudah diterima ADR 0003 untuk `site/`. Berkas authoring (`*.prompt.md`, `*.d.ts`, `*.card.html`) sengaja tidak ikut divendor, konsisten dengan ADR 0003.
