# Jam adzan dihitung otomatis metode Kemenag, bukan lagi bagian dari Sumber Data yang diedit tangan

**Mempersempit [0001](0001-static-site-hand-edited-data-file.md).** Jam adzan di Sumber Data (`sourceData.js`) sebelumnya di-hand-type oleh pengurus sebagai satu baris waktu per shalat tanpa tanggal, dan cepat basi karena jam shalat sungguhan bergeser tiap hari mengikuti posisi matahari. Kami memutuskan jam adzan dihitung otomatis saat build/CI (bukan di browser pengunjung) mengikuti metode resmi Kementerian Agama RI (sudut fajar −20°, isya −18°, mazhab Syafi'i untuk Ashar, ihtiyat resmi Kemenag), lewat kalkulator murni `site/src/lib/prayerTimeCalculator.js` (`computePrayerTimes({ latitude, longitude, date })`, memakai `adhan` sebagai mesin astronomi Meeus, dengan sudut dan mazhab dibakukan mengikuti metode Kemenag) dan skrip build-time `site/scripts/generate-prayer-times.mjs` yang menghasilkan dataset ±1 tahun ke depan (di-gitignore, tidak dikomit) sebagai bagian dari `npm run build`. Sumber Data (`sourceData.js`) tidak lagi menyimpan jam adzan sama sekali — hanya `location` (koordinat) dan `iqamahOffsets` (kebijakan lokal per shalat, dalam menit setelah adzan) yang tetap hand-typed, karena Kemenag tidak mendefinisikan iqamah. `deriveSiteData` mengambil `times` hari ini dan `week` (7 hari nyata ke depan untuk tabel "Pekan ini", menggantikan trik interpolasi offset sebelumnya) dari dataset hasil generate ini, menerapkan `iqamahOffsets`. Tanggal yang dibutuhkan tidak ditemukan di dataset diperlakukan sebagai bug integritas build — `deriveSiteData` melempar error jelas, dan skrip generate berhenti dengan exit non-zero bila lokasi tidak valid — situs tidak pernah tayang dengan jadwal kosong/salah secara diam-diam. Konsekuensinya: build butuh langkah generate tambahan sebelum `vite build` (otomatis, tanpa langkah manual pengurus), dan akurasi jadwal sekarang bergantung pada `adhan` serta koordinat yang tersimpan di `location.js`, bukan lagi pada ketelitian pengurus mengetik ulang jam tiap kali berubah. ADR `0001` tetap berlaku untuk seluruh konten lain di Sumber Data (agenda, donasi, statistik, galeri, dll) — hanya jam adzan yang dipersempit keluar dari cakupannya.
