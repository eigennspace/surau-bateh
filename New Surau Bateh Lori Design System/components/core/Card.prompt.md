Wadah konten dasar untuk kajian, pengumuman, dan panel jadwal.

```jsx
<Card tone="sand" interactive><h3>Kajian Tafsir Ba'da Maghrib</h3></Card>
```

Nada: `default` putih di atas latar pasir, `sand` untuk kartu di atas kartu putih, `brand` maroon untuk sorotan tunggal, `dark` untuk blok Isya/malam, `calm` teal untuk status waktu berjalan.
