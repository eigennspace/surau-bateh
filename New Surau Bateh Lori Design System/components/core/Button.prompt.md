Tombol aksi utama; pakai untuk donasi, daftar kajian, dan CTA hero.

```jsx
<Button tone="primary" size="lg" icon="hand-coins">Salurkan Infak</Button>
<Button tone="secondary" icon="calendar-days">Jadwal Kajian</Button>
```

Varian: `primary` (maroon, CTA tunggal per layar), `accent` (emas, dipakai di atas latar gelap/foto), `secondary` (outline maroon), `ghost` (nav & aksi tersier), `dark` (slate, dipakai di kartu jadwal). Semua tombol berbentuk pil penuh — jangan ubah radius.
