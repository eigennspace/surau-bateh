Kaki situs; satu-satunya blok gelap penuh pada halaman.

```jsx
<Footer columns={[{title:'Layanan',links:['Jadwal Salat','Kajian Rutin']}]} />
```

Prop `address` hanya boleh memuat alamat yang benar-benar diketahui. Alamat jalan lengkap sudah dikonfirmasi pengurus (12 Agu 2026): "Jl. Lori Lubuk Minturun, Lubuk Minturun, Kec. Koto Tangah, Kota Padang, Sumatera Barat 25586" — dipakai sebagai default dan dialirkan dari `sourceData.js` (`contact.address`) lewat `App.jsx`. Teks alamat dibungkus link ke `addressHref` (default: `contact.maps`) supaya bisa langsung dibuka di Google Maps.

Di bawah teks alamat ada peta mini (`mapEmbedSrc`), diminta pengurus (12 Agu 2026) sebagai pratinjau visual, bukan cuma link teks. Lebar mengikuti `maxWidth: 280` (sama seperti teks alamat), tinggi **fixed 300px**.

Sempat dicoba `flex: 1` + `height: '100%'` di blok kiri supaya peta otomatis meregang mengisi tinggi baris grid ("full align sampai ke bawah" kolom Layanan/Surau/Jamaah, permintaan pengurus 12 Agu 2026) -- **tidak dipakai**, terbukti tak bisa bekerja: kolom kanan (link list, 3-4 item) secara alami jauh lebih pendek daripada blok kiri (logo+alamat+peta+ikon sosial), jadi blok kiri sendiri yang menentukan tinggi baris grid. Elemen `flex:1` di dalam kontainer yang tingginya ditentukan oleh dirinya sendiri (termasuk `minHeight` elemen itu) tidak punya "sisa ruang" untuk ditumbuhi -- flex-basis 0 + flex-grow di situasi ini selalu resolve ke `minHeight`-nya sendiri (circular sizing, bukan bug). Kalau suatu saat kolom kanan berisi lebih banyak link sehingga secara alami lebih tinggi dari blok kiri, baru `flex:1` akan benar-benar berguna dan bisa dicoba lagi. Sengaja pakai endpoint `https://maps.google.com/maps?q=LAT,LNG&z=16&output=embed` (tanpa API key) alih-alih Google Maps Embed API resmi -- situs ini statis tanpa proses setup credential, dan endpoint ini sudah dipakai luas bertahun-tahun meski tidak didokumentasikan resmi oleh Google (risiko: bisa berubah/dihentikan sewaktu-waktu tanpa jaminan; kalau itu terjadi, ganti ke Embed API resmi + API key). Koordinat berasal dari `SB_DATA.location` (`site/src/data/location.js`), dibangun di `App.jsx`, bukan hardcode di komponen ini. Iframe diberi `pointerEvents: 'none'` dan dibungkus `<a>` ke `addressHref` -- peta jadi murni pratinjau visual yang klik-nya diteruskan ke link Maps, bukan peta interaktif sendiri (mencegah scroll-zoom peta membajak scroll halaman).
