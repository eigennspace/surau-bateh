Navigasi utama di ponsel — lima tujuan tersering, tersembunyi sendiri di layar lebar.

```jsx

```

Sasaran sentuh minimal 56px. Aktif ditandai warna maroon + ikon, bukan latar berwarna. Selalu pasangkan dengan `padding-bottom` pada isi halaman agar konten terakhir tidak tertutup.
